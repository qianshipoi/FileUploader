# 排查与常见问题

## 双击之后没有任何窗口

九成是**静默启动**：设置里打开「静默启动」后，双击 exe 只会进托盘、不弹主窗口。

- 点任务栏右下角的托盘图标；Win10 默认会把它收进 `^` 溢出区，展开后才看得到。
- 托盘右键 →「打开主窗口」。
- 进托盘时右下角会有一次「已在托盘运行 / 点托盘图标打开」的气泡提示（约 4 秒）。
- 想改成双击就弹窗口：设置 → 启动与托盘 → 关掉「静默启动」。

顺带：同一份 exe 只会跑一份，重复双击不会多出进程——它会把已有窗口叫到前台。

## 窗口里只有一页红字 / 白屏

那是 Reactor 渲染时抛出的异常，页面上会带异常类型与堆栈。把 `%APPDATA%\FileUploader\crash.log`（便携版是 `data\crash.log`）发出来，一般就能定位。

已知的一类：`Theme resource 'xxxBrush' not found or is not a Brush` —— 某些环境下 WinUI 的主题资源取不到。现在所有主题画刷都走 `ThemeBrushes` 的安全取法（多级 key + 兜底颜色），取不到时只在 `crash.log` 里记一条「主题资源取不到，已用兜底颜色：xxx」，界面照常显示。

## 排查闪退

未处理异常会写到 `%APPDATA%\FileUploader\crash.log`（含完整堆栈）；简洁模式的原生窗口若创建失败，主窗口也会自动回来，不会留下"窗口没了、托盘也没了"的僵局。托盘图标点不回来（前台激活被系统拒绝）、开机自启写注册表失败、自更新失败，也都会在这里留记录。

## 检查更新失败

- 需要能访问 `api.github.com`：墙内/公司网络可能要配系统代理或 `HTTPS_PROXY`。
- 匿名接口每小时 60 次限流，超了会提示稍后再试。
- 失败只影响这一张卡片，其它功能不受影响；也可以直接去 [Release 页](https://github.com/qianshipoi/FileUploader/releases) 手动下载。

## 自更新替换失败

- 程序装在 `Program Files` 这类需要管理员权限的目录时，替换会失败并提示；把程序放到有写权限的目录（桌面、D 盘、U 盘），或手动下载新 exe 覆盖。
- 替换过程中会用 `.old` 备份、失败自动还原，所以不会出现"目录里没有 exe"的情况。

## 拖拽浮现气泡没反应

- 设置 → 启动与托盘 →「右下角拖拽浮现上传气泡」是否被关掉了。
- 多屏时气泡会跟到光标所在那块屏；如果拖到屏幕边缘仍无反应，先确认拖的确实是**文件**（拖文本/拖图片不会弹出）。
- 诊断日志：设环境变量 `FU_FLASH_DEBUG=1` 后气泡会往 `%TEMP%\fu-flash.log` 写状态。

## 大文件传到一半断了

先别急着重新拖一遍，看列表里那条记录的状态：

- **「已中断 · 已传 xx%」**：重启过程序。直接点那一行的「继续」，只补没传完的分片。
- **「已取消」**：自己点了取消。点「重试」同样从断点继续。
- **「失败」**：看看红色的原因。网络/服务端临时问题就点「重试」（每片已有 3 次自动重试）；签名错、桶名错、没权限这类要先改设置。
- 想彻底不传了：点「移除」。它会把服务端已经收到的分片也清掉，不会在桶里占着看不见的空间。

什么时候**续不上**（只能重新传）：本地文件被改过或删了、换了桶 / 换了 Endpoint、换了机器，或者手动删了 `%APPDATA%\FileUploader\uploads`。续传记录超过 7 天也会被自动清掉。

> 说明：分片上传要求对象键保持一致，所以续传**永远沿用中断前那次的对象键**（URL 里那串时间目录不会变）。

## 已知限制

- 分片上传是**顺序**传片：同一个文件同一时间只传一片（多个文件之间仍然并发 3 路）。够用，但没有做片内并行。
- 断点续传依赖本地记录（`%APPDATA%\FileUploader\uploads`）和原始文件没变；换机器、清记录、改文件都要重新传。
- 「打包成 ZIP 上传」是一次拖入打一个包（不会按子文件夹拆包），打包期间 `%TEMP%` 需要约等于源体积的空闲空间；而且**只打包文件**，空目录不会进包。
- 检查更新要能访问 `api.github.com`（见上）。
- 自更新只替换**当前目录里的 exe**（见上）。
- 签名链接最长 7 天（阿里云与 S3 SigV4 一致限制），更长的链接需要自己做 CDN + 私有鉴权。
- 只支持 Windows；界面文字为中文。
- Reactor 目前是 preview 版（`0.1.0-preview.16`），升级小版本时分析器可能给出新的建议警告。
